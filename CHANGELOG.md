# Changelog

## 0.2.0 - Initial Public Release

- Added persistent template-driven zone authoring for Items.
- Added managed Region creation from measured templates.
- Added support for simple, ring, composite line, and composite ring zone types.
- Added on-enter, on-exit, on-move, start-turn, and end-turn trigger normalization.
- Added simple effects, compatible dnd5e activity triggers, targeting rules, difficult terrain, linked walls, and linked lights.
- Added built-in/user profiles and profile import/export.
- Added global movement interruption modes for supported movement triggers.
- Added public `game.persistentZones` API.
- Added English and French localization.
